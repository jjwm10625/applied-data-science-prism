## 위젯 세션 잔존 증거

위젯 제외 이전 정제본(/tmp/hilingual-widget-before/clean_events.parquet)을 대조.
전체 관측 기간의 (user_id, session_id)별로 widget_count가 있고
widget_count/session_start/session_end 이외 이벤트가 없는 세션을 분류.
해당 세션의 08/30 이후 session_start/end 83,327건이 현재 데이터에 남아 있음
(884명, 42,146개 세션; null/-1 세션 ID 없음).
혼합 세션에도 위젯 이벤트가 있으므로 위젯과 같은 세션이라는 이유만으로 모두 제거해서는 안 됨.

예: amplitude_id 1451681213330
- 09/01 22:00:34.616: session_start, widget_count, session_end가 같은 시각/세션
- 09/02 22:01:06.582: 동일 패턴
- 현재 09/15 피처: event_count_7d=14, active_days_7d=7, recency_days=1, churn_label=0

SDK/앱 내부에서 왜 발생했는지는 로그만으로 확정할 수 없으며 담당자 확인 필요.

## 민감도 분석 (적용하지 않은 가정)

08/30 이후 session_start/end 전체를 활동 근거에서 제외하는 가정으로 비교.
이 가정은 위젯 전용 세션 제거보다 넓으므로, 아래 수치는 위젯 전용 세션 수정의 확정 효과가 아님.
08/30 이후 기존 기준일 75,604행을 유지해 비교했으며, 재선정한 학습 모집단의 이탈률이 아님.

| 지표 | 현재 평균/비율 | 가정 적용 평균/비율 | 값이 달라지는 행 |
|---|---:|---:|---:|
| active_days_7d | 2.058 | 0.558 | 21,856 |
| active_days_28d | 7.101 | 2.390 | 29,286 |
| recency_days | 9.831 | 23.001 | 27,541 |
| churn_label=1 | 63.84% | 84.85% | 15,885 |

가정 적용 시 과거 28일 활동이 없어 학습 대상에서 빠질 행: 13,742행.
미래 7일 라벨 때문에 08/30 이전 기준일도 영향을 받음(전체 변경 라벨 16,864행).
상세 비교: widget_session_diagnostic.csv, 변경 라벨 예시: widget_session_label_examples.csv.

## 권장 조치

위젯 전용 세션의 자동 시작/종료 이벤트를 실제 활동으로 볼지 애널리틱스 담당자와 확인.
위젯 전용으로 판별된 세션의 해당 기간 이벤트를 제거하고 이벤트 수, 세션 수,
활동일, recency, 라벨, 학습 대상, 알림 선호도를 함께 재계산하는 방향 권장.
click_widget 또는 실제 앱 활동이 포함된 세션은 유지.
사용자 전체 삭제로 처리하면 정상 활동까지 손실됨.
